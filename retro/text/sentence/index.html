Module sentence

Source
Expand description

This module provides structures and utilities for working with font glyphs and sentences composed of these glyphs. It includes:

  • The Sentence struct: Represents multiple Glyphs glued together, allowing efficient manipulation and iteration of text data.
  • The Glyphs struct: Represents a slice of glyph references from the same alphabet, providing convenient access to the underlying data.
  • The font8x8_sentence macro: Facilitates the creation of Sentence objects from literals, enabling a concise and readable syntax for embedding text data with specified alphabets.

The main use case of this module is to manage and render text efficiently, especially in graphics or text-intensive applications where control over individual glyphs and alphabets is necessary.
