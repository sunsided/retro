Expand description

Renders a sentence or text on the frame buffer.

§Arguments

  • buffer - A mutable reference to the frame buffer where the text will be drawn.
  • x - The x-coordinate of the top-left corner where the text will be rendered.
  • y - The y-coordinate of the top-left corner where the text will be rendered.
  • text - The Sentence reference containing the text to render.
  • color - The color of the text in the frame buffer (RGBA format).
  • scale - The scaling factor to enlarge the text (each pixel in the glyphs will be expanded by scale times in both dimensions).
  • italic - Whether the text should be rendered with an italic slant.

§Notes

  • This function draws each glyph from the specified Sentence on the frame buffer. Characters are spaced apart by their scaled dimensions.
  • Characters are rendered in the order defined by the Sentence.
  • If italic is set to true, a slant effect is applied as defined in draw_char.
  • Ensures that rendered glyphs do not exceed the dimensions of the frame buffer.
