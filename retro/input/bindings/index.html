§Key Bindings Module

This module provides a macro, define_key_bindings, to define mappings between high-level input intents and specific key bindings in a structured and efficient manner. It generates a struct for key bindings and an enum for intents, ensuring readability and maintainability in handling key-related actions in applications.

§Overview

  • KeyBindings struct: Stores key mappings for each input intent.
  • InputIntent enum: Represents high-level input intents or actions.
  • Implements the Default trait to provide default key mappings.
  • Provides a method to retrieve the key for a specific intent.

§Usage Design

The macro define_key_bindings! allows developers to define key mappings and associated high-level intents in one concise place. This minimizes boilerplate and keeps intent-to-key management centralized and consistent across the codebase.
