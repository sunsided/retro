Module input

Source
Expand description

This module provides key handling utilities for defining and managing key bindings, debouncing key inputs, and processing high-level key intents.

It contains the following submodules:

  • bindings: Used to define specific key mappings and their associated high-level intents.
  • debounce: Facilitates key debounce handling to avoid unintended repeated input.
  • handling: Provides mechanisms to handle key input events and map them to high-level actions.

The module makes use of the minifb crate for key input handling and incorporates pre-defined key bindings for common actions, such as toggling a CRT effect, modifying settings, or exiting a context.
